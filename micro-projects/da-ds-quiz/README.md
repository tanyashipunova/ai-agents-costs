# Тренажер Python для подготовки к тестовым заданиям

Интерактивный консольный тренажер на Python, который помогает освежить и закрепить навыки чтения и анализа кода, темы из Data Analytics / Data Science. Особенность — текстовые формулировки переведены в программный код.

## План структуры проекта

Репозиторий планируется организовать следующим образом:

```text
micro-projects/da-ds-quiz/
├── docs/
│   ├── quiz-plan.md         # План разработки тренажера
│   └── quiz-prototype-v0.py # Прототип тренажера
├── data/
│   └── questions.json       # База данных с вопросами, кодом и ответами
├── src/
│   ├── __init__.py          # Делает папку src модулем Python
│   ├── main.py              # Точка входа, запускает тренажер
│   └── trainer.py           # Логика работы теста и валидации ввода
├── .gitignore               # Исключение системных файлов (например, __pycache__)
├── LICENSE                  # Лицензия MIT
└── README.md                # Описание проекта
```

---

## Дисклеймер / Disclaimer

* Проект является **независимой учебной разработкой**. 
* Программа создана исключительно в целях демонстрации навыков программирования на Python, знаний в Data Analytics / Data Science и помощи соискателям в подготовке к техническим секциям.

---

## Как запустить проект (план)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd da-ds-quiz
   ```

2. Запустите главный скрипт:
   ```bash
   python src/main.py
   ```
