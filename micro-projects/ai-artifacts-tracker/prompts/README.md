# Рекомендуемая организация артефактов

## Ведение базы промптов

**База промптов:**
- Папка `/prompts` с подпапками по назначению: `qa`, `summarization`, `code-review`, `creative`, `debug`.
- Каждый промпт — отдельный файл `.md` или `.txt` с заголовком и метаданными.
- Пример структуры файла в `.md`:
```
# QA_Customer_Support_v4

## Описание
Отвечает на вопросы клиентов по продукту X. Тон дружелюбный, без жаргона.

## Входные данные
- query: вопрос пользователя
- context: фрагмент из базы знаний (RAG)
- product_version: версия продукта

## Шаблон промпта
Ты — помощник поддержки продукта X версии {{product_version}}. Ответь кратко и дружелюбно. Используй только предоставленный контекст. Если контекста недостаточно —скажи: «Уточните, пожалуйста, детали».

Контекст:
{{context}}

Вопрос:
{{query}}
```
