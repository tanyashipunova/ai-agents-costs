## Организация документации

**Цель:** единая структура папок, понятные имена файлов, предсказуемые пути для хранения артефактов ИИ-проектов.

**Рекомендуемая структура папок:**
```
/ai-artifacts-tracker
  /docs                  # общая документация (стандарты, регламенты, политики)
  /knowledge             # база знаний для RAG (исходные тексты, статьи, выдержки)
  /prompts               # библиотека промптов и шаблонов
  /scenarios             # ИИ‑сценарии, пайплайны, workflow
  /assistants            # описания ИИ‑ассистентов (роли, инструкции, ограничения)
  /solutions             # описания ИИ‑решений (архитектура, требования, метрики)
  /reports               # отчёты, метрики качества, история экспериментов
  /versions              # версионность артефактов (git, changelog, архивы)
  /tools                 # скрипты, утилиты, конфиги для локальной работы
```

**Имена файлов.** Использовать префиксы и даты, например: `YYYY-MM-DD_<тип>_<тема>.md` или `YYYY-MM-DD_<тема>_vN.md`. Пример: `2024-10-25_prompt_customer_qa_v3.md`.
