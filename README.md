## Overview

This repository contains my ongoing AI research and hands-on experiments. It combines:

- **Research notes** in Markdown: key insights, datasets, models, and evaluation metrics  
- **Mermaid.js diagrams** showing system architecture, data flow, and model pipelines  
- **Micro-projects** in Python: small, self-contained scripts demonstrating AI concepts

Each project is designed to be educational, reproducible, and technically sound — ideal for learning, prototyping, or sharing ideas.
